Configuration

These are environment variables, not settings. The bot token lets anyone holding it send messages as the church, so it is never stored in the database and never shown on this page — only whether it is present.

TELEGRAM__BOTTOKEN=<from BotFather> TELEGRAM__BOTUSERNAME=RMChurchBot AUTH__TELEGRAMWEBHOOKSECRET=<a long random string>

Set these where the application is deployed — in Coolify, under the application's Environment Variables — then restart it. Changing them needs a restart because they are read at startup.

First-time setup

  1. In Telegram, message @BotFather and send /newbot.
    It replies with a token and your bot's @username.
  2. Put the token, the username and a random webhook secret into the environment variables above, then restart the application.
  3. Come back here and press Register webhook.
    This tells Telegram where to deliver messages, and the secret it must send with them.
  4. Ask someone to sign in and press Connect Telegram.

Telegram only delivers to a public HTTPS address. A local development machine cannot receive updates without a tunnel.
